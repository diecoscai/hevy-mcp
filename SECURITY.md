# Security Policy

The full threat model and operational notes live at [`docs/security.md`](./docs/security.md).

## Reporting a vulnerability

Open a [private security advisory](https://github.com/diecoscai/hevy-mcp/security/advisories/new) on this repository. **Do not file a public issue** for security concerns.

We aim to acknowledge reports within 5 business days. Fixes for confirmed issues ship in the next patch release.

## Supported versions

Only the latest published version on npm receives security fixes. Pin a specific version in your MCP client config and watch [Releases](https://github.com/diecoscai/hevy-mcp/releases) for advisories.
